# Lume — Seu espaço para descobrir novas histórias

O **Lume** é uma plataforma web criada para quem gosta de literatura e busca uma maneira simples de descobrir novos livros, explorar diferentes gêneros e organizar suas leituras.

A ideia do projeto surgiu do interesse em desenvolver um espaço onde os leitores pudessem encontrar informações sobre obras literárias e, ao mesmo tempo, construir sua própria biblioteca virtual.

O Lume permite pesquisar livros, conhecer novos autores, explorar títulos em alta e salvar obras em uma biblioteca pessoal, organizando-as entre as categorias "Quero ler", "Lendo" e "Já li". Além disso, os usuários podem criar uma conta e marcar seus livros favoritos.

## Sobre o desenvolvimento

O projeto foi desenvolvido utilizando React, JavaScript e Tailwind CSS na construção da interface, com foco em uma navegação simples, intuitiva e responsiva.

No backend, foram utilizados Node.js e Express para desenvolver a API responsável pela autenticação dos usuários e pelo gerenciamento de suas bibliotecas e favoritos.

Para o armazenamento das informações, foi utilizado PostgreSQL por meio do Supabase. Já os dados dos livros, como títulos, autores, capas e descrições, são obtidos através da API pública da Open Library.

A aplicação está hospedada no GitHub Pages, enquanto o backend utiliza o Render.

## Tecnologias utilizadas

**Frontend:** React, JavaScript, Vite, Tailwind CSS e React Router.

**Backend:** Node.js e Express.

**Banco de dados:** PostgreSQL e Supabase.

**Integrações:** Open Library API.

**Hospedagem:** GitHub Pages e Render.

## Funcionalidades

O Lume conta com recursos que permitem aos usuários explorar e organizar suas experiências de leitura:

- Pesquisa de livros por título e palavras-chave.
- Exploração de obras por gêneros literários.
- Visualização de livros em alta.
- Consulta de informações sobre livros e autores.
- Cadastro e autenticação de usuários.
- Biblioteca pessoal com organização das leituras.
- Lista de livros favoritos.
- Interface adaptada para diferentes tamanhos de tela.

## Objetivo do projeto

O Lume também representa uma oportunidade de colocar em prática conhecimentos em desenvolvimento web, desde a construção de interfaces até a integração entre frontend, backend e banco de dados.

Durante seu desenvolvimento, foram trabalhados conceitos de consumo de APIs, autenticação, persistência de dados, responsividade, versionamento de código e publicação de aplicações web.

O projeto continua em desenvolvimento, com a intenção de incorporar novas funcionalidades e aprimorar a experiência dos leitores.
